# 📸 Photobooth App

Ý tưởng: app photobooth chạy ngay trên trình duyệt — mở camera, đếm ngược, chụp 4 tấm, ghép thành dải ảnh (photo strip) kiểu Hàn Quốc và tải về.

## Tính năng
- [x] Mở camera (webcam / điện thoại)
- [x] Đếm ngược 3 giây trước mỗi lần chụp
- [x] Chụp 4 tấm, ghép thành photo strip dọc
- [x] Chọn màu khung
- [x] Tải ảnh về (PNG)

## Ý tưởng mở rộng
- Filter ảnh (đen trắng, vintage, sepia)
- Sticker / khung theo chủ đề (sinh nhật, cưới, Tết)
- Chia sẻ qua QR code
- Chế độ kiosk cho sự kiện (màn hình cảm ứng + máy in)
- Bố cục khác: lưới 2x2, 3 tấm, polaroid

## Chạy thử
Mở `index.html` bằng trình duyệt (camera cần `localhost` hoặc HTTPS):

```bash
npx serve .
```

Hoặc bật GitHub Pages cho repo.
